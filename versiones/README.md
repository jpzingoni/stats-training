# Versiones anteriores del tablero

Copias congeladas del tablero para comparar con la versión actual (`app/`). No se publican
(están fuera de `app/`) y leen los mismos datos de `app/data/`, así que muestran datos al día.
Para abrir una: doble clic en `versiones/<versión>/index.html`.

| Versión | Qué es | Etiqueta de Git |
|---|---|---|
| v1.1 | Tablero antes del rediseño según `app/DESIGN.md` (12/10/2026) | `v1.1` |

Si cambia la estructura de los datos, una copia vieja puede dejar de verse bien: es una
referencia visual, no se mantiene.
